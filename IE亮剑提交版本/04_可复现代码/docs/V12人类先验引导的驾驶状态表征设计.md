# V12：人类先验引导的驾驶状态表征学习

## 1. 目标与当前结论

V12要解决的问题是：

> 能否把V10中“人如何区分驾驶风险”的判断方式写进自监督表征学习，让模型先学出可解释的驾驶状态，再用少量事故监督判断未来风险？

V12不把人的判断写成固定事件分数，也不把“疲劳一定导致事故”当作因果事实。人的知识只规定三件事：

1. 哪些事件大致描述同一类驾驶状态；
2. 哪些信息属于暴露机会、行为状态、控制反应、近端险情、历史严重事件和观测质量；
3. 哪些状态转移值得模型重点学习和做随机对照。

模型仍然学习每种事件的重要程度、事件应归入哪个状态的比例、状态之间的关系强度以及最终风险率。

V12推荐主线调整为 **Human-Guided Risk-Chain SSL，简称 HRC-SSL**。状态遮蔽负责学会“当天是什么状态”，风险链预测负责学会“这个状态接下来会怎样变化”：

```text
逐日事件与上下文
    ↓
事件级编码
    ↓ 人类分组提供软初始化，不固定权重
六个驾驶状态槽
    ↓ 逐状态因果时间编码
状态感知遮蔽 + 未来状态变化预测
    ↓
可学习的有向风险转移图
    ↓
预训练驾驶状态表征
    ↓
右删失风险微调
    ↓
每日风险率 q、未来40天概率 p40、状态依据
```

首轮不再使用V11那种“从一段公共向量预测另一段公共向量”的全局JEPA。V11已经表明事件感知Masked预训练稳定有效，而当前全局JEPA低于Scratch。V12保留Masked作为表征底座，同时把预测目标改成明确的U/C/P状态变化、未来事件包和转移方向，使SSL真正学习风险链。

## 2. V10和V11告诉了我们什么

### 2.1 V10中值得保留的部分

V10的20→40开发OOF结果中，Flat、Role、Chain分别为0.7331、0.7578、0.7611：

- Role相对Flat提升约0.0247，配对区间为正，说明事件角色和风险阶段的组织有价值；
- Chain只比Role高约0.0033，只比同参数随机图高约0.0020，不能证明具体风险链拓扑很强；
- 七日中间阶段监督带来约0.0086方向改善，但不同预测期并不完全一致；
- 质量门控没有改善主锚点。

因此V12保留“角色、阶段、状态”的语义组织，让SSL通过未来状态变化主动学习风险链，同时用全连接动态和随机语义链作负对照。人工固定图不作为唯一信息通道。

### 2.2 V11中值得保留的部分

V11三种子结果表明：

- Masked相对同架构Scratch平均提升约0.0429 AUC，方向稳定；
- Contrastive只有小幅改善，区间跨0；
- JEPA没有改善；
- Masked所有折都选择1000步，说明表征学习尚未在当前预算内明显过度训练；
- Masked表示没有坍塌，但原模型最后把多种状态压成64维公共向量，状态含义仍不够清楚。

因此V12继续使用Masked学习，同时不再过早压缩成单个公共向量。六个状态槽在预训练、微调和解释阶段都保持独立。

### 2.3 方法依据

- [Relational inductive biases](https://arxiv.org/abs/1806.01261)说明可以通过实体、关系和组合规则给网络加入关系归纳偏置；
- [GraphMAE](https://arxiv.org/abs/2205.10803)表明对图节点特征做遮蔽恢复可以学习结构化表征；
- [GraphMAE2](https://arxiv.org/abs/2304.04779)进一步使用重新遮蔽解码和隐藏表征预测约束重建；
- [S3VAE](https://openaccess.thecvf.com/content_CVPR_2020/papers/Zhu_S3VAE_Self-Supervised_Sequential_VAE_for_Representation_Disentanglement_and_Data_Generation_CVPR_2020_paper.pdf)提供了将稳定因素和动态因素分开的思路。

这些方法只提供建模启发。V12的数据规模、标签和事件含义不同，必须通过车辆级OOF消融判断是否有效。

## 3. V12要学习的六种驾驶状态

每天形成六个状态槽，每个槽是32维向量。

| 状态槽 | 人的含义 | 主要输入 | 在风险判断中的作用 |
|---|---|---|---|
| **O：暴露与机会** | 当天有多少驾驶和事件触发机会 | 里程、时长、夜间、活跃状态、盲区环境事件 | 区分高暴露与高单位风险 |
| **U：上游危险行为** | 驾驶倾向或注意状态正在变差 | 超速、疲劳、闭眼、困倦、分心、看手机 | 描述风险来源和长期驾驶倾向 |
| **C：控制稳定性** | 行为是否已经影响车辆控制 | 车道偏移、压线、IMU加速度和角速度 | 描述风险是否从行为升级到控制异常 |
| **P：近端险情** | 是否已经接近碰撞或紧急状态 | 车距过近、前碰撞预警 | 描述短期风险升级 |
| **H：严重历史与复发** | 过去是否发生事故或未遂事故 | 11803、11804及recency | 描述复发倾向，保持强收缩 |
| **Q：证据质量** | 当前“没看见事件”是否可信 | 摄像头异常、轨迹/IMU覆盖、缺失标记 | 表示证据可靠度，不等同于危险程度 |

事件的初始归属沿用V10已经审计的角色和阶段，但采用**软归属**：

```text
A[event, state] = softmax(learned_logits + human_prior_bias)
```

人工先验只让一个事件在初始化时更偏向某个状态槽。`A`在训练中可以调整，一个事件也可以同时贡献给多个状态。例如分心既可进入上游状态，也可能通过学习给控制状态少量贡献。

增加很弱的归属正则：

```text
L_assign = CrossEntropy(human_primary_state, A)
```

它只防止小数据下状态槽完全失去含义。环境和质量事件不施加“风险必须为正”的约束，所有事件的最终风险方向仍由数据学习。

## 4. 数据边界保持不变

V12不改变标签、车辆划分或最终概率定义：

- 478台可监督车辆中382台开发、96台锁定；
- 开发池使用冻结的5折车辆划分；
- 同一车辆的全部日期、遮蔽窗口和锚点只能在同一侧；
- 外折验证车的无标签序列也不能进入该折预训练；
- 锚点仍为14/20/30/40/50/53；
- 风险微调继续使用首次11803/11804的右删失似然；
- 96台锁定车在模型和超参数冻结前不评分；
- Day60只生成未来40天候选概率，没有本地真实标签。

V12的自监督预训练可以读取外折训练车辆自身的完整日序列，但下游锚点预测始终只输入锚点及以前数据。

## 5. 统一编码器

### 5.1 事件级输入

继续使用V11审计过的24类事件，每类每天8项：

```text
log次数、log报警段、log每百公里率、log每小时率、是否发生、
里程是否可见、时长是否可见、夜间里程占比
```

另有31项暴露、轨迹、IMU、质量与缺失上下文。设备号、绝对经纬度和未来统计不进入模型。

### 5.2 从事件到状态槽

```text
每个事件8项输入
  → 共享MLP 8→32→32
  + event-id / role / stage embedding
  → 24个事件向量
  → 软归属矩阵A加权汇总
  → U/C/P/H四个事件状态槽

暴露与环境 → O状态槽
摄像头、覆盖与缺失 → Q状态槽
IMU动态同时进入C槽的条件编码
```

汇总时保留事件内容相关的动态gate，因此同一种事件在不同暴露和近期状态下可以有不同作用。软归属矩阵用于“进入哪个状态”，动态gate用于“这一天该事件信号有多重要”，两者不能混为一个权重。

### 5.3 逐状态时间编码

六个状态槽分别通过共享参数的4层因果TCN：

```text
width = 32
dilation = 1/2/4/8
感受野约31天
```

加入state-id embedding区分六类状态。共享TCN减少参数，同时允许稀疏的P/H状态借助U/C状态学到一般时间规律。

时间编码后仍保留：

```text
Z ∈ R^[batch, day, 6 states, 32]
```

V12不立即把它压成单个64维向量。后续预训练任务和风险头都直接读取六个状态表示。

### 5.4 可学习的风险转移图

V12不再把风险链仅作为微调阶段的解释结构，而是在SSL阶段直接学习有方向、有时间滞后的状态转移。对每个截止日`t`，学生只能读取`1..t`日，预测`t+1`、`t+3`和`t+7`的状态变化。

对每个预测距离`h∈{1,3,7}`学习一个稀疏有向矩阵`A_h`：

```text
Z_hat[j,t+h] = Predictor_h(
    Z[j,t] + Σ_i A_h[i,j] × Message_i_to_j(Z[i,t]),
    O[t], Q[t]
)
```

其中：

- `U→C、U→P、C→P`只作为初始偏好，不是固定边；
- 自环允许状态持续，反向边允许模型表达恢复或数据中真实存在的反向关联；
- `O`作为暴露条件，决定一次状态变化有多少发生机会；
- `Q`控制证据可信度和损失掩码，不被解释成危险程度；
- 每条边同时学习1、3、7日的权重，由此得到状态升级通常发生在哪个时间尺度。

人工关系先验只在训练前30%步骤施加很弱的约束，随后衰减到0。最终边强度必须由未来状态预测误差决定：

```text
L_graph = 0.01 × sparsity(A)
        + anneal(0.02 → 0) × prior_distance(A, A_human)
```

风险链采用残差结构，原状态始终保留：

```text
Z_chain = Z_temporal + β × GraphMessage(Z_temporal),  β初始为0
```

这样模型可以学到“U通常先于C、C通常先于P”，也可以拒绝不符合数据的人工关系。后续风险头同时读取`Z_temporal`和`Z_chain`，不会因风险链学错而丢失原始信息。

## 6. 表征底座：人类引导的状态遮蔽

V12使用一套由浅到深的遮蔽任务，不同时堆入对比学习或全局JEPA。

### 6.1 第一层：事件信号包遮蔽

沿用V11已经验证有效的方式。遮住某个事件时，同时遮住：

```text
次数、报警段、每公里率、每小时率、发生标记
```

保留必要的暴露条件和独立`ssl_mask`。模型必须区分真实零值、原始缺失和人工遮蔽。原始缺失位置不计算重建误差。

损失继续拆开计算：

```text
是否发生             BCE
正值事件强度         Huber
连续上下文           Huber
质量与缺失状态       BCE
```

### 6.2 第二层：完整驾驶状态遮蔽

V12的关键改动是，不只随机遮单项事件，还会选一个状态槽，将其对应的完整信号连续遮住2–5天：

- 遮U：同时遮住超速、疲劳和分心事件包；
- 遮C：同时遮住车道控制事件和对应IMU片段；
- 遮P：同时遮住车距和前碰事件；
- 遮O：遮住暴露与环境上下文；
- 遮Q：遮住质量记录，但保留“这是人工遮蔽”的标记；
- H极稀疏，只以较低概率遮蔽，不让事故零值主导任务。

状态类别采用均衡采样，避免高频U状态占据绝大多数梯度。模型只能利用同日未遮蔽状态和此前历史恢复被遮住的状态，不能查看该日之后的数据。

### 6.3 第三层：隐藏状态恢复

一个无梯度EMA教师读取未遮蔽训练序列，学生读取遮蔽序列。学生除恢复原始值外，还恢复教师在被遮位置的对应状态向量：

```text
L_state = SmoothL1(
    normalize(student_state_at_mask),
    stopgrad(normalize(teacher_state_at_mask))
)
```

这与V11的失败JEPA有本质区别：

- 不预测尚未观察的整段未来；
- 只恢复当前被遮住的语义状态；
- 六个状态分别计算后等权平均，不让暴露量淹没近端状态；
- 原值重建仍然保留，隐藏预测只作辅助约束。

参考GraphMAE2的做法，对解码器输入再进行一次随机re-mask，减少解码器直接复制编码器细节的机会。

### 6.4 状态遮蔽损失

主配置固定为：

```text
L_mask = 1.00 L_event_feature
       + 0.50 L_context
       + 0.25 L_state
       + 0.01 L_assign
```

这些权重在首轮实验前冻结，不在外折OOF上连续搜索。状态槽和普通事件遮蔽共用同一个编码器和解码器。

## 7. 核心SSL：学习风险链

### 7.1 训练样本怎样形成

从外折训练车辆的60日序列中随机抽取截止日`t`。学生只读取第`1..t`天，EMA教师读取同一训练车辆截至目标日的真实序列。只在`t+h≤60`时构造对应预测距离：

```text
历史1..t日 → 第t+1日状态
历史1..t日 → 第t+3日状态
历史1..t日 → 第t+7日状态
```

未来记录只作为SSL目标，不能进入学生编码器。外折验证车辆和96台锁定车辆仍完全不进入预训练。

### 7.2 目标一：未来隐藏状态变化

直接预测未来状态本身容易学成“复制当前状态”，因此主要预测变化量：

```text
delta_target[j,h] = stopgrad(
    teacher_Z[j,t+h] - teacher_Z[j,t]
)

L_transition = SmoothL1(
    predicted_delta[j,h], delta_target[j,h]
)
```

`U/C/P`分别计算后等权平均，不能让高频U状态淹没稀疏P状态。`O/Q`作为条件输入，也预测自身变化作为辅助检查，但不算风险升级边。连续多日没有变化的样本下采样，避免模型只学会输出零变化。

### 7.3 目标二：未来可观察事件包

隐藏状态可能出现教师和学生一起坍塌的问题，因此同时预测真实未来窗口中是否出现对应事件，以及正值时的强度：

```text
U_t → 未来h日疲劳/分心/超速事件包
U_t,C_t → 未来h日车道/IMU控制异常包
U_t,C_t,P_t → 未来h日近距/前碰事件包
```

发生与否使用BCE，正值强度使用Huber。没有可靠事件源或覆盖不足的位置不当负例，直接从损失中排除。正例权重只按外折训练车辆估计并截断到20。

这项任务使转移图必须解释实际观测，而不能只拟合教师向量。事故和未遂事故`11803/11804`不作为SSL未来目标；它们仍只进入右删失监督损失。这样可以诚实地区分“无标签状态动态学习”和“最终事故监督”。

### 7.4 目标三：路径一致性

同一个7日变化既可以一步预测，也可以由较短转移组合得到。增加很弱的路径一致性：

```text
Transition_7(Z_t) ≈ Transition_3(Transition_3(Z_t))
Transition_3(Z_t) ≈ Transition_1重复三次(Z_t)
```

它约束不同滞后矩阵描述同一套状态动力学，但权重保持较小，避免误以为每天变化速度恒定。

### 7.5 完整SSL损失

```text
L_ssl = 1.00 L_mask
      + 0.50 L_transition
      + 0.50 L_future_event
      + 0.05 L_path_consistency
      + L_graph
```

状态遮蔽保证模型理解当天，未来状态和事件预测保证模型理解变化方向，稀疏转移图把这些变化整理成可读的风险链。首轮固定这些权重，不根据外折结果连续搜索。

### 7.6 必须设置的风险链负对照

需要三种相同预算的对照：

1. **无方向对照**：只恢复被遮状态，不预测未来；
2. **全连接动态对照**：预测同样的未来目标，但使用普通MLP，不使用状态有向图；
3. **随机语义链对照**：保留图参数量和目标频率，随机置换U/C/P名称及人工先验边。

只有可学习风险链稳定超过前两者，并且合理语义链超过随机链，才能说SSL学到的风险链对下游风险判断有用。

## 8. 下游风险判断

预训练结束后删除重建解码器和未来事件分类头，保留状态编码器、转移图和状态变化预测器。风险微调对每个锚点提取：

```text
每个状态的全历史均值       chronic_s
每个状态最近14天均值        acute_s
U/C/P最近7天相对前7天变化    trend_s
P/H距最近发生的时间表示      recurrence_s
Q最近14天证据状态            evidence
风险链预测的1/3/7日变化      expected_transition
U→C、C→P等边的当期激活量     chain_activation
```

风险头先把每个状态压成一个可审计的小表示，再做联合判断：

```text
[O, U, C, P, H, Q的chronic/acute/trend
 + expected_transition + chain_activation]
                ↓ concat + quality/mask
              64维小MLP
                ↓
       每日首次事故风险率 q
                ↓
p_H = 1 - (1-q)^H
```

最终仍然只输出一个风险率，不手工把六个状态分数相加。模型同时保存每个状态遮蔽后的概率变化，作为“模型依赖了哪些状态”的解释。

监督损失沿用V11：

```text
L_finetune = L_right_censored_survival
           + 0.10 L_next_stage
```

微调仍分为10轮冻结编码器探针和完整解冻训练。编码器学习率`1e-4`，风险头`1e-3`，最多60轮，由外折训练车辆内部验证选择轮数。

## 9. 实验矩阵

V12最多分三阶段运行。最终主候选是Stage 3的HRC-SSL，但每一阶段必须回答一个独立问题，前一阶段失败就停止后续复杂化。

### Stage 1：人的状态分组是否有价值

| 实验 | 改动 | 目的 |
|---|---|---|
| **V12-0 V11-M++** | V11 Masked结构，统一1500步预算 | 排除训练更久本身带来的提升 |
| **V12-A State-MAE** | 六状态槽 + 事件包/状态块遮蔽 | 检验状态化表征本身 |
| **V12-A-shuffle** | 参数相同，随机置换事件到状态槽的人工归属 | 检验合理分组是否优于任意分组 |

只有A相对0方向改善，并且A优于A-shuffle，才进入Stage 2。

### Stage 2：预测状态变化是否有价值

| 实验 | 改动 | 目的 |
|---|---|---|
| **V12-B Dynamics-SSL** | A + 1/3/7日状态变化和未来事件预测，使用同容量全连接预测器 | 检验学习状态动力学是否有效 |
| **V12-B-now** | 参数相同，只重建当前状态，不预测未来 | 排除“多一个预测头”的解释 |

只有B相对A方向改善，并稳定优于B-now，才进入Stage 3。

### Stage 3：有语义的风险链是否有价值

| 实验 | 改动 | 目的 |
|---|---|---|
| **V12-C HRC-SSL** | 用可学习稀疏有向转移图替换B的全连接预测器，加入弱人类初始化和路径一致性 | V12主候选 |
| **V12-C-no-prior** | 同一个有向图，但所有边同分布初始化且没有人工关系正则 | 区分图结构收益与人类先验收益 |
| **V12-C-shuffle** | 相同参数、目标和预算，随机置换U/C/P语义及先验边 | 检验合理风险链是否优于任意链 |

只有C至少不低于B，并且优于C-shuffle，才说明风险链建模有价值；只有C进一步优于C-no-prior，才能把增益归因于人的风险链初始化。

V12首轮不加入全局对比学习、无语义未来JEPA、VQ离散码本或大Transformer，避免在500台车上同时引入过多不确定因素。

## 10. 固定训练预算

各阶段内部所有模型使用相同预算：

```text
state width                32
TCN blocks                 4，dilation 1/2/4/8
relation rounds            1，残差系数从0初始化
prediction horizons        1/3/7日
transition predictor width 32
dropout                    0.10
SSL batch                  64个车辆窗口
SSL steps                  固定1500
AdamW SSL lr               3e-4
weight decay               1e-3
gradient clip              1.0
EMA momentum               0.99 → 0.999
```

V11所有Masked折都在1000步达到搜索上限，因此V12预先固定1500步。V12-0也使用1500步，保证结构实验不会把额外训练量误认为状态先验收益。如果1500步时验证重建损失仍持续下降，只记录为后续风险，本轮不依据外折结果继续增加预算。

预计编码器约7万至12万参数，包含转移预测器的完整风险网络控制在20万以内。全连接动态对照通过无效占位层匹配HRC-SSL的参数量，避免把容量差异误认为风险链收益。

各阶段先使用种子2026完成五折。只对通过全部门槛的一个候选使用2027和2028复验；最终仍采用三种子逐车平均。96台锁定车保持关闭。

## 11. 接受与停止规则

### 11.1 主指标

- 20→40车辆级OOF ROC-AUC；
- PR-AUC和Brier；
- 14→40、30→30、40→20、50→10、53→7稳定性；
- 相对V12-0、V11 Masked和V3的配对车辆bootstrap；
- 冻结编码器风险探针。
- 1/3/7日未来状态变化误差和U/C/P未来事件PR-AUC；
- 合理方向与反向方向的转移预测差异。

### 11.2 接受一个结构的最低条件

1. 相对上一阶段AUC方向改善，且至少3/5折不为负；
2. Dynamics-SSL必须优于B-now；HRC-SSL必须不低于全连接Dynamics-SSL；
3. HRC-SSL必须优于C-shuffle；只有优于C-no-prior才能宣称人类风险链先验有效；
4. Brier恶化不超过0.005；
5. 14→40和20→40不能出现相反的大幅变化；
6. 状态表示不坍塌，且不是简单记忆车辆身份；
7. 三随机种子提升方向一致后，才能成为V12最终候选。

若ΔAUC小于约0.01且区间跨0，保留更简单的前一阶段。不能因为人的解释听起来合理就接受无实测增益的模块。

## 12. 表征诊断与解释

V12必须分别回答“学会了什么状态”和“这些状态是否帮助事故风险”。保存以下结果：

### 12.1 状态表征健康度

- 六个状态各自的维度标准差、有效秩和协方差；
- 同一状态在相邻日期的平滑程度；
- 不同状态间的余弦相似度，防止六个槽学成同一向量；
- 用状态表示识别车辆身份的准确率，过高而风险不改善视为记忆；
- 原始重建损失和隐藏状态恢复损失。
- 预测变化量的方差以及预测零变化的比例，防止动力学头退化为常数；
- `A_1/A_3/A_7`的稀疏度、方向不对称性和跨折稳定性。

### 12.2 状态是否符合人的含义

- 遮蔽超速/疲劳/分心后，U槽变化应大于Q槽；
- 遮蔽车道和IMU后，C槽变化应最大；
- 遮蔽近距/前碰后，P槽变化应最大；
- 低质量事件不应把U/C/P机械压成“安全”；
- A与A-shuffle、B与B-now、C与C-no-prior/C-shuffle必须配对比较。

这些检查只验证表示是否与预定义语义一致，不证明真实因果关系。

### 12.3 风险解释

对每辆车保存：

- 六个状态的长期、近期和变化摘要；
- 单独遮蔽O/U/C/P/H/Q后的概率变化；
- 学到的事件软归属和动态gate；
- 1/3/7日风险链边强度、滞后分布和当期激活量；
- 证据质量等级和预测路由。

最终交付表仍只保留`gpsno,prediction,probability`，解释字段保存在内部安全卡，不进入比赛CSV。

## 15. 当前冻结决定

V12设计阶段冻结以下原则：

- 以V11已验证的Masked预训练为表征底座，主SSL任务改为预测1/3/7日状态变化；
- 人的判断进入六个驾驶状态、遮蔽策略和可学习的风险转移图；
- 事件到状态采用可学习软归属，不固定事件权重；
- 风险链在SSL中学习方向、强度和滞后，人工边只作短期弱初始化；
- 11803/11804不伪装成SSL目标，仍由右删失监督损失学习最终事故风险；
- 先验证状态分组，再验证未来动态预测，最后验证有语义的风险链；
- 风险链必须同时比较全连接动态、无人工先验和随机语义链对照；
- 下游继续输出右删失日风险率，保持与V11完全可比；
- V12代码、五折实验、最终重训与三列表格已经完成；实测结果和取舍见下节。

### 16.2 20→40车辆级OOF

| 方法 | AUC | PR-AUC | Brier | 相对State-MAE ΔAUC |
|---|---:|---:|---:|---:|
| State-MAE | **0.775154** | 0.574721 | 0.170662 | 0 |
| 随机状态分组 | 0.764163 | 0.549993 | 0.175753 | −0.010991 |
| Dynamics-SSL | **0.776081** | 0.576874 | 0.171328 | +0.000927 |
| HRC无人工先验 | 0.771128 | **0.596916** | **0.170438** | −0.004026 |
| HRC合理风险链 | 0.770873 | 0.587088 | 0.171680 | −0.004282 |
| HRC随机语义链 | 0.768157 | 0.583714 | 0.171559 | −0.006997 |

State-MAE相对随机状态分组高**0.0110 AUC**，五折中4折方向不差，Brier也更好；配对区间仍跨0，因此只能说语义状态组织有方向性证据，不能称为已经得到明确统计证明。

Dynamics-SSL比State-MAE只高**0.000927**，配对95%区间`[−0.015106,+0.018844]`，五折变化为`+0.0204/+0.0165/−0.0295/+0.0080/−0.0104`。它在14→40和30→30较好，但50→10和53→7更差，没有形成稳定收益。

合理HRC低于Dynamics **0.0052 AUC**，也略低于无先验图；虽然比随机链高约**0.0027**，差值太小。各折图残差系数绝对值约0.15–0.18，但正负方向跨折翻转，说明模型确实启用了图分支，却没有学到稳定一致的风险传播方向。人的风险链初始化没有通过对照。

### 16.3 最终保留模型

设计阶段已经规定：若新增模块`ΔAUC < 约0.01`且配对区间跨0，应保留更简单的前一阶段。因此不能机械选择数值最高的Dynamics-SSL，V12最终保留**State-MAE**：

- 20→40 AUC：**0.775154**，bootstrap区间`[0.720111,0.820197]`；
- PR-AUC：**0.574721**；
- Brier：**0.170662**；
- Accuracy@0.5：**0.717277**；
- 五折选轮：`15/18/24/26/15`，最终使用中位数**18轮**；
- 14→40、30→30、40→20、50→10、53→7 AUC分别为**0.776490、0.780274、0.783565、0.760534、0.738741**。

相对V11三种子Masked集成，V12 State-MAE为**+0.001086 AUC**，配对区间`[−0.016174,+0.017880]`；相对V3为**−0.012301**，区间`[−0.042682,+0.014929]`。V12改善了状态可解释性和PR-AUC，但没有证明总体排序优于V11或V3，因此不继续用开发OOF搜索更多风险链结构，也不进行额外随机种子扩展。
