# V9：因果先验与风险链模型实验设计

## 1. 目标不是手工打分，而是给学习过程正确的结构

这套方案把人的判断写成**结构、归一化方式、允许的交互和弱先验**，不把“理论上更危险”直接写成固定权重。数据库是观察数据，无法仅凭相关性识别某行为对事故的因果效应，因此以下模型应称为“因果启发的风险预测模型”，不能声称得到因果结论。

用一个简化图表示：

```text
驾驶暴露 ───────────────→ 事故机会 ───────────┐
道路/环境 ─→ 行为触发机会 ─→ 近端报警 ───────┤
驾驶倾向 ─→ 危险状态 ─→ 控制异常 ─→ 紧急状态 ─┼→ 未来事故/未遂事故
设备质量 ───────────────→ 事件检测概率 ───────┘
历史严重事件 ───────────────────────────────→ 复发风险
```

观测到的事件次数更接近：

```text
真实行为强度 × 暴露机会 × 道路触发机会 × 设备检测概率
```

因此模型必须区分四件事：

1. **未来有多少驾驶机会；**
2. **单位暴露下的危险驾驶倾向；**
3. **风险是否从一般行为升级为近端险情；**
4. **零事件究竟表示安全，还是观测不充分。**

## 2. 事件角色划分

分组只定义共享方式和候选风险链，不直接规定最终权重大小。

| 角色 | 当前事件 | 模型中的处理 |
|---|---|---|
| 历史严重/复发 | `11803`事故、`11804`未遂事故 | 合并“历史严重事件”并保留单项；重点使用近期次数、距最近一次天数、每公里率；强收缩事故单项，防止极稀疏事件过拟合 |
| 近端碰撞信号 | `30000`前碰撞预警、`30005`车距过近 | 单独建组；使用每公里率、最近7天变化、复发和二者共现/先后关系 |
| 明确危险状态 | 场景超速、闭眼、困倦、看手机、注意力分散 | 使用与机制匹配的分母；允许弱正向先验，不固定人工严重度 |
| 控制质量/驾驶风格 | 左右偏离、长时间压线、打哈欠、电话、低头、抽烟 | 更依赖频率、持续性和与下游事件共现；强于单次原始次数的收缩 |
| 环境机会 | 左右盲区报警，以及近端信号中由拥堵带来的部分 | 允许正负方向；与驾驶小时、交通密度代理和其他行为共同解释 |
| 观测质量 | 摄像头遮挡、摄像头角度扭转、轨迹/IMU覆盖、长间隔 | 不与普通危险事件相加；用于证据可靠度和独立质量风险支路 |
| IMU连续信号 | 加速度峰值、波动、角速度峰值及覆盖 | 当前只能作为控制/紧急操作代理；现有预处理没有直接生成“急刹、疑似碰撞、疑似侧翻”标签，不能按这些名称监督 |

分母按机制选择：超速、车距和碰撞预警优先用公里；疲劳和分心优先用驾驶小时，困倦可补充夜间驾驶小时；盲区事件优先用驾驶小时；历史严重事件同时保留次数、每公里率和recency。所有模型同时保留分子与分母，避免速率在低暴露时失真。

## 3. 共同监督协议

所有实验继续使用V3–V8的冻结协议，避免把结构改进与评估变化混在一起：

- 478台候选监督车中382台开发、96台锁定；开发池5折按整车隔离。
- 锚点固定为`{14,20,30,40,50,53}`，输入只使用锚点及以前记录。
- 输出锚点后的next-event日风险；损失继续使用右删失离散时间似然，同车锚点先平均。
- 主指标为20→40车辆级OOF ROC-AUC，Brier和PR-AUC为主要辅助指标；其他锚点分开报告。
- 预处理、模型、选轮和任何先验强度只使用外折训练车；96台锁定车不用于选择。
- 低证据的22台车继续单独标记，不把无记录解释成安全。

## 4. 实验0：风险链特征的线性基线

### 目的

先回答“这套人类结构化思路本身是否有价值”，避免一开始把收益混到神经网络容量中。

### 输入

在V3/V5的landmark特征上新增三类明确特征：

1. **分层摘要：** 每一风险角色的长期率、最近7天率、前7天率、变化量、最大recency和活跃事件类型数。
2. **风险升级：** 最近窗口的最高风险层、严重层占比、从一般状态到近端状态的升级次数。
3. **预注册链条：** 疲劳→车道控制、分心→车道控制、超速→近距/前碰、近距→前碰、控制异常→近端险情。对每条链计算同日共现、1–3天有向跟随、1–7天有向跟随，并按公里或驾驶小时归一。

有向链特征只允许使用锚点内完整发生的两端。例如计算第`t`天样本时，只有`d+Δ≤t`的转移可以进入输入。

### 模型

沿用V3的elastic-net日风险逻辑回归。参数量和损失不变，仅替换为结构化特征。

### 对比

```text
E0-a：V3原特征
E0-b：V3原特征 + 分层摘要
E0-c：E0-b + 共现特征
E0-d：E0-c + 有向风险链特征
```

如果E0-d不优于E0-b，就没有理由立刻上复杂的风险链网络。

## 5. 实验1：分层神经加性风险模型 HNAM

### 目的

让每类行为学习自己的非线性响应，同时保留“长期倾向、近期恶化、事件角色”三个可解释层次。

### 架构

```text
每种事件：长期率/近期率/前期率/recency/次数/分母
        ↓ 各事件小型响应函数 f_e（共享骨干 + 类型偏置）
事件级 chronic_e 与 acute_e
        ↓ 按角色组内收缩聚合
严重历史、近端信号、危险状态、控制风格、环境机会
        ↓
少量预注册二阶交互
        ↓
日风险 logit
```

只开放五个有机制依据的二阶交互：

- 疲劳 × 夜间驾驶；
- 分心 × 车道控制异常；
- 超速 × 急转/IMU波动；
- 车距过近 × 前碰撞预警；
- 历史严重事件 × 近期近端信号。

其余部分保持加性，避免小样本下任意交互。风险事件权重采用组内层次收缩：稀疏类型更靠近组均值，覆盖充分的类型可以偏离。人的分层只形成先验均值和正则强度，不规定固定权重顺序。

对暴露归一后的历史严重事件、近距和前碰信号，可以比较三种约束：无符号约束、软单调惩罚、硬单调。首选软约束：

```text
L = L_survival
  + λ_group × 组内偏差惩罚
  + λ_sign × 违反预期方向的局部斜率惩罚
```

环境和质量变量不施加正向约束。可解释的单变量响应函数可参考[Neural Additive Models](https://papers.neurips.cc/paper/2021/hash/251bd0442dfcc53b5a761e050f8022b8-Abstract.html)；部分单调约束的可行性可参考[Deep Lattice Networks](https://arxiv.org/abs/1709.06680)。

### 参数预算

控制在约3千至8千参数。输出每个事件的长期贡献、近期贡献、组内收缩后权重和五项交互贡献。它们是预测贡献，不是因果效应。

### 对比

```text
E1-a：普通加性网络（无分层先验）
E1-b：分组 + 组内收缩
E1-c：E1-b + chronic/acute拆分
E1-d：E1-c + 五项预注册交互
```

## 6. 实验2：观测质量门控模型 Q-HNAM

### 目的

处理“视觉事件为零可能是安全，也可能是摄像头异常导致漏检”。

### 架构

```text
摄像头遮挡/角度异常/覆盖/活跃日/长间隔
                 ↓
证据可靠度 g_visual ∈ [0,1]

视觉行为表示 r_observed
                 ↓
r_visual = g_visual × r_observed
         + (1-g_visual) × 训练车组先验表示

r_visual + 非视觉事件 + 质量本身的风险表示 → HNAM风险头
```

低质量时不把观测率除以很小的检测概率，因为这会制造极端风险；而是把视觉证据平滑回训练组先验，同时允许“设备异常/管理配合度”通过独立支路影响风险。训练中对视觉事件通道做少量整组遮蔽，使模型学会在信息不足时回退。

### 对比

```text
E2-a：E1最佳模型，不做质量门控
E2-b：只把质量当普通输入
E2-c：质量门控，但无通道遮蔽训练
E2-d：质量门控 + 视觉通道遮蔽训练
```

必须增加压力测试：同一车辆的视觉事件全部遮蔽后，概率不应异常降到“更安全”；质量良好的真实零事件与低质量零事件应得到不同证据等级。由于没有独立的事件通道在线日志，`g_visual`只能解释为模型的证据可靠度，不能解释为真实检测概率。

## 7. 实验3：有方向的时间风险链网络 ChainNet

### 目的

V7让所有日期自由注意，但没有把“疲劳→控制异常→近端险情”这样的方向写入结构。ChainNet只允许预注册风险链传播，检验风险升级是否比自由注意力更适合小样本。

### 每日节点

```text
疲劳、分心、超速/激进、车道/控制、近距、前碰/紧急、严重历史、环境、质量
```

每个节点由其对应事件和暴露归一特征形成4–8维状态。允许的边包括：

```text
疲劳/分心 → 车道与控制
超速/激进 → 近距与控制
车道/控制 → 前碰/紧急
近距 → 前碰/紧急
前碰/紧急 → 严重风险
质量 → 证据门控（不进入事故链传播）
环境 → 触发机会和基线风险
```

### 网络

```text
每日节点状态
  ↓ 共享的1–3天和1–7天时间卷积
按固定有向图做2轮消息传递
  ↓
最近7天池化 + 前7天池化 + 全历史池化 + 最后一天
  ↓
右删失日风险头
```

只做两轮消息传递，因为两轮已覆盖“上游行为→控制异常→近端信号”。参数控制在约5千至15千。辅助任务使用锚点内的历史前缀：由截至第`d`天的上游节点预测`d+1..d+7`的下游节点；目标日必须被输入掩码遮住。所有前缀仍按车辆留在同一折，辅助样本不能被当成新的独立车辆。

### 对比

```text
E3-a：显式风险链特征 + 线性模型
E3-b：相同每日节点 + 无边的时间卷积
E3-c：固定风险链图 + 时间卷积
E3-d：E3-c + 历史前缀辅助任务
```

额外做日期置换负对照：在每车锚点内随机打乱日期，E3-c的链条贡献应明显减弱；静态分层模型应基本不受影响。神经Hawkes过程也能表示事件间相互激发，但其自由度和连续时间假设对本题几百辆车较重，首轮不采用；相关原始方法见[Neural Hawkes Process](https://arxiv.org/abs/1612.09328)。

## 8. 实验4：暴露量 × 单位风险的因子化生存模型

### 目的

直接实现“事故机会≈未来暴露×单位暴露风险”，避免模型把历史里程既当风险又当分母后自行猜测其作用。

### 架构

```text
历史里程/时长/活跃日/趋势
           ↓ exposure head
未来日均暴露预测 ê

HNAM或ChainNet行为表示
           ↓ risk head
单位暴露风险 λ

每日风险 q = 1 - exp(-ê × λ)
40天概率 p40 = 1 - exp(-40 × ê × λ)
```

在早期锚点，未来可观察天数内的真实里程和驾驶小时只作为exposure head的辅助目标，不输入风险模型；超出第60天仍视为未知。总损失为：

```text
L = L_survival(q)
  + λ_exp × Huber(log1p(未来日均暴露), log1p(ê))
```

比较两种单位风险：每公里风险和每驾驶小时风险，只预注册一种主方案，另一种作敏感性检查。离散时间风险与右删失似然继续沿用[Nnet-survival](https://peerj.com/articles/6257/)所代表的标准形式。

### 对比

```text
E4-a：最佳行为编码器直接输出每日风险q
E4-b：预测未来暴露ê，但不进入风险，只作辅助任务
E4-c：ê × 单位暴露风险λ的因子化模型
```

若E4-b改善而E4-c不改善，说明辅助监督有用，但强制乘法结构不适合；若E4-c主要改善Brier而非AUC，说明它更可能改善概率尺度而不是车辆排序。

## 9. 推荐的执行顺序和停止规则

不同时启动所有神经网络。推荐顺序：

1. **先做E0：** 验证分层、共现和有向链特征有没有信息增量。
2. **再做E1：** 验证层次收缩、chronic/acute和少量交互是否优于平坦事件网络。
3. **E1有效后做E2：** 单独验证质量门控；若视觉遮蔽压力测试失败，即使AUC略升也不接受。
4. **E0的有向链有效后做E3：** 否则不训练ChainNet。
5. **最后做E4：** 在最稳的行为编码器上检验暴露因子化。

## 10. 实验执行结果（2026-09-23）

| 阶段 | 变体 | 20→40 OOF AUC | Brier | 结论 |
|---|---|---:|---:|---|
| E0 | V3原始特征 | 0.7875 | 0.1679 | 仍是本轮最强 |
| E0 | +角色汇总 / +共现 / +方向链 | 0.7656 / 0.7690 / 0.7717 | 0.1718 / 0.1714 / 0.1717 | 方向链没有可靠增量 |
| E1 | 平坦 / 层级 / 长短期 / 固定交互 | 0.7232 / 0.7226 / 0.7211 / 0.7249 | 0.1877 / 0.1882 / 0.1883 / 0.1875 | 层级先验未改善小网络 |
| E4 | 直接 / 暴露辅助 / 暴露因子化 | 0.7504 / 0.7490 / 0.7520 | 0.1832 / 0.1839 / 0.1836 | 暴露预测改善但未转化为风险增益 |

E0 完整方向链相对原始 V3 的配对 ΔAUC 为 **−0.0157**，95% 区间 `[−0.0366,+0.0040]`；E1 固定交互相对 V3 为 **−0.0625**，区间 `[−0.0984,−0.0277]`；E4 因子化相对 V3 为 **−0.0355**，区间 `[−0.0571,−0.0139]`。

因此按第 9 节的预注册条件停止 E2 和 E3：E1 没有成立，质量门控不继续；E0 的方向链没有成立，ChainNet 不继续。E4 已完成。当前主模型继续使用 V3 Model 0。本轮没有读取或评分 96 台锁定车，也不能用本地数据验证 Day60→未来40天的真实表现。

每个阶段只保留预注册的有限变体，不根据外折OOF继续搜索组别、链条或先验强度。接受一个变化至少要求：主AUC方向改善、Brier没有明显恶化、五折不是单折驱动、配对车辆区间支持或至少不明显反向，并通过相应结构压力测试。若差异处在车辆bootstrap波动内，选择参数更少、假设更少的版本。

## 10. 必须增加的结构验证

| 检查 | 预期行为 |
|---|---|
| 等比例增加事件次数与里程 | 单位风险支路应基本稳定；总风险只能通过未来暴露支路合理变化 |
| 锚点后数据任意修改 | 该锚点所有特征和预测完全不变 |
| 低质量下视觉事件设为零 | 模型回到低证据先验附近，不能自动判为安全 |
| 打乱每车历史日期 | 静态模型基本不变；风险链模型的有向链贡献下降 |
| 删除极稀疏的历史事故单项 | 严重事件组合仍可工作，整体预测不应崩溃 |
| 标签置换 | 完整选型流程AUC回到随机水平 |
| 按事件组整组消融 | 报告近端、危险状态、控制、环境、质量各组的车辆级配对变化 |

最终解释应同时给出暴露贡献、长期倾向、近期升级、风险链和证据质量，不把单个学习权重称为行为的客观严重程度。
