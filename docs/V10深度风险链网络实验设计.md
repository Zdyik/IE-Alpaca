# V10：深度风险链网络实验设计

## 1. V10解决什么问题

V9把事件角色、共现和风险链压成车辆级统计，再交给线性模型或静态小网络。它验证了这些手工统计没有超过V3，但没有真正回答下面这个问题：

> 如果把人的判断写进逐日神经网络内部，让网络自己学习事件强度、时间延迟和链条贡献，能否比普通时序网络更好？

V10专门回答这个问题。它从每日原始事件序列开始训练，不读取V3的landmark汇总特征，不继承V3逻辑回归的系数，也不把人工严重程度直接当权重。V3只作为已有成绩参照。

V10使用三类先验：

1. **共享先验：** 同一角色的事件共享部分参数，稀疏事件可借助同组事件学习。
2. **关系先验：** 只允许有合理方向的事件链传递信息，边的强度由网络学习。
3. **观测先验：** 摄像头异常影响视觉事件的可信度，不直接等同于安全或危险。

这种做法属于深度网络中的关系归纳偏置，而不是给V3增加人工特征。固定实体和关系结构、再让网络学习关系强度的思路可参考[Relational inductive biases, deep learning, and graph networks](https://arxiv.org/abs/1806.01261)。

## 2. 输入仍然是逐日序列

每辆车在锚点`t`形成长度为`t`的日序列。第`t+1`天及之后的任何记录都不能进入输入。

### 2.1 事件节点

24种事件每天各形成一个节点。每个节点输入：

```text
当天原始次数
当天独立报警段数
是否发生
每100公里平滑率
每驾驶小时平滑率
夜间暴露占比（疲劳类的条件信息）
对应分母是否可靠
```

网络同时看到分子、分母和速率。低里程日不会因为一个很大的比值被误判，也不会因为只看原始次数而退化为里程预测器。

平滑率使用训练前固定公式，例如：

```text
rate_km   = 100 × count / (distance_km + 100)
rate_hour = count / (drive_hours + 1)
```

平滑常数不根据OOF结果搜索。当前日表只有夜间公里、没有夜间驾驶小时，因此首轮使用夜间公里占比作为疲劳条件变量，不伪造夜间小时率。事件编码器自己学习各事件更依赖公里、小时还是夜间暴露。

### 2.2 非事件节点

额外设置三个节点：

- **车辆动态节点：** 当前已有的加速度峰值、加速度波动、角速度峰值、有效IMU窗口；不虚构“急刹”“碰撞”“侧翻”等当前预处理没有给出的离散标签。
- **暴露节点：** 当日公里、驾驶小时、夜间公里、活跃状态和最近变化。
- **质量节点：** 轨迹/IMU覆盖、无效距离比例、长间隔、摄像头遮挡和角度异常。

因此每天先形成27个原始节点：24个事件节点和3个非事件节点。24个事件完成各自编码和动态门控后，再汇成速度、疲劳、分心、控制、近距、前碰、严重历史、环境、质量9个状态节点；TCN实际处理这9个状态节点和3个非事件节点。这样仍保留逐事件权重，同时把最耗时的时序计算从27条序列缩减为12条。

### 2.3 事件角色和风险阶段

每个事件同时有三个可学习标识：

```text
event-id embedding：区分具体事件编码
role embedding：严重历史、近端、危险状态、控制、环境、质量
stage embedding：上游行为、控制异常、近端险情、严重事件
```

这些embedding只告诉网络“哪些事件可能共享规律”。它们不规定`闭眼一定比打哈欠权重大`，也不规定所有事件必须正相关。

## 3. 主模型：RiskChainNet

```text
每天27个节点
     ↓
共享节点编码器 + event/role/stage embedding
     ↓
每个事件的上下文权重 gate(e,t)
     ↓
节点内多尺度时间卷积（1–3、1–7、1–14天）
     ↓
固定方向图上的两轮信息传播
     ↓
全历史慢性状态 + 最近14天急性状态 + 最近7天升级状态
     ↓
质量证据支路 + 暴露上下文
     ↓
每日首次事故/未遂风险率 q
```

### 3.1 节点编码和动态事件权重

所有事件先通过共享的小型MLP：

```text
数值输入 → Linear(输入维度,16) → GELU → Linear(16,16)
```

再加入事件、角色和阶段embedding。每个事件每天产生一个动态门：

```text
a(e,t) = sigmoid(MLP(h(e,t), 暴露(t), 质量(t)))
h'(e,t) = a(e,t) × h(e,t)
```

`a(e,t)`是该事件在当前车辆、当前日期和当前观测质量下的使用程度。它比V4/V5的单个全局权重更灵活：相同的前碰预警，在低暴露日、高暴露日和摄像头异常日可以有不同贡献。

原始gate不能直接解释为客观严重程度。最终事件重要性通过“遮蔽该事件后车辆风险变化”的OOF置换/消融结果报告。

### 3.2 多尺度时间编码

每个节点独立沿时间轴使用共享的残差TCN：

```text
Conv1d(kernel=3, dilation=1)
Conv1d(kernel=3, dilation=2)
Conv1d(kernel=3, dilation=4)
```

感受野覆盖约15天，可以表达最近几天的突然恶化和两周内的持续状态。这里选TCN，是因为序列只有60天、车辆数较少，卷积参数共享比再次扩大Transformer更克制。TCN作为序列模型的通用起点可参考[An Empirical Evaluation of Generic Convolutional and Recurrent Networks for Sequence Modeling](https://arxiv.org/abs/1803.01271)。

时间卷积严格因果：第`d`天的隐藏状态只能读取第`1..d`天。这不仅防止辅助任务偷看未来，也让“上游事件预测后续下游事件”具有明确时间边界。

### 3.3 有方向的滞后图传播

V10不把同一天内两个报警的先后顺序当成已知事实，因为日表没有小时级顺序。方向传播只读取前1–7天的上游状态：

```text
疲劳/分心 ──→ 车道与控制异常
超速/激进 ──→ 车距过近、控制异常
车道/控制 ──→ 前碰撞预警
车距过近 ──→ 前碰撞预警
前碰撞预警 ──→ 严重历史状态
```

每类边学习自己的滞后分布和强度：

```text
m_v(t) = Σ(u→v) α(u,v) Σ(δ=1..7) softmax(k_uv)[δ] · W_type h_u(t-δ)
h_v_new(t) = LayerNorm(h_v(t) + m_v(t))
```

- 图结构固定，避免382台开发车上搜索任意24×24关系。
- `α(u,v)`和滞后权重由数据学习；不支持的链可以收缩到接近0。
- 保留残差自通道，即使人工边不合适，节点自身信息仍可通过。
- 只做两轮传播，覆盖“危险行为→控制异常→近端险情”，避免深层图网络过平滑。

### 3.4 慢性、急性和升级状态

传播后的节点表示分成三种池化：

- **慢性状态：** 全历史按有效驾驶日平均，表示长期驾驶倾向。
- **急性状态：** 最近14天可学习衰减池化，表示近期恶化。
- **升级状态：** 最近7天只聚合控制、近端和严重阶段，表示风险是否走到链条后半段。

三者concat后进入风险头。这样网络能区分“长期一直有少量报警”和“最近一周突然从分心升级到FCW”。

### 3.5 质量门控只作用于对应传感器

`41006/41021`首先按驾驶员监控摄像头质量处理，只门控`410xx`驾驶员视觉行为。除非数据说明确认`300xx`与它们来自同一摄像头，否则不门控前碰、车距和车道事件。

```text
g_dms = sigmoid(quality_net(遮挡、角度、覆盖、活跃日))
h_dms = g_dms × h_observed + (1-g_dms) × learned_missing_prior
```

质量节点还有独立支路，可以学习设备异常或管理配合度与风险的关系。低质量不会简单把事件清零成“安全”。训练时以固定概率0.15整组遮蔽DMS行为节点，让回退路径真正被训练。

## 4. 输出和损失

### 4.1 主输出

风险头输出一个日风险率：

```text
q = sigmoid(risk_head(chronic, acute, escalation, exposure, quality))
p40 = 1 - (1-q)^40
```

训练继续使用首次`11803/11804`的右删失似然。同车六个锚点先平均，再对车辆平均。该损失能使用30、40、50、53日锚点的部分随访，不把未观察的未来天数填成0。离散时间神经生存模型的似然形式可参考[Nnet-survival](https://arxiv.org/abs/1805.00917)。

### 4.2 风险链辅助任务

在每个训练锚点内部选若干历史截点`d`，使用截至`d`日的因果隐藏状态预测：

```text
未来1–3天是否出现控制异常
未来1–7天是否出现近端事件
未来1–7天是否出现事故或未遂事故
```

目标日必须满足`d+k≤anchor`。辅助头位于逐日因果编码器上，不能读取目标日期的输入。所有截点仍属于原车辆，不作为额外独立车辆。

```text
L = L_survival + 0.10 × L_next_stage + λ_shrink × L_group
```

严重事件极稀疏，辅助任务按外折训练车计算正例权重并设置上限，避免少数事故支配梯度。首轮只比较辅助权重`0`和固定`0.10`，不在OOF上连续调参。

## 5. V10实验矩阵

所有变体使用相同日输入、节点宽度、TCN深度、风险损失、车辆折和内层选轮。每次只打开一个结构。

| 实验 | 架构变化 | 回答的问题 |
|---|---|---|
| **V10-A Flat-EventTCN** | 共享事件节点编码器 + TCN + 普通池化；只有event-id，无角色、图或质量门控 | 新逐日节点网络本身是否比V7稳定 |
| **V10-B Role-EventTCN** | A + role/stage embedding + 组内收缩 + 慢性/急性/升级三路池化 | 人类事件分层进入网络后是否有用 |
| **V10-C Chain-TCN** | B + 两轮固定方向滞后图传播 | 风险链结构是否提供额外信息 |
| **V10-C-shuffle** | 与C完全相同的参数量和边数，但固定随机置换事件连接 | C的收益来自合理拓扑还是只是多了一层 |
| **V10-D Chain-Aux** | C + 历史截点的下一阶段辅助监督 | 风险链是否需要中间监督才能学到 |
| **V10-E Quality-Chain** | D + DMS质量门控 + 0.15整组遮蔽 | 模型能否区分真实零事件和低质量零事件 |

### 为什么需要随机图对照

只比较“无图”和“有图”无法说明人类链条是对的，因为有图模型同时增加了参数和计算。`V10-C-shuffle`保留完全相同的层数、参数量、边数和节点度数，只改变边连接。只有C稳定优于C-shuffle，才能认为预注册风险链拓扑本身有帮助。

## 6. 固定模型规模和训练设置

首轮不搜索大范围超参数：

```text
node width          24
event/role/stage embedding  8/4/4
TCN residual blocks 3（dilation 1/2/4）
graph message rounds 2
dropout             0.15
batch size          512辆车（每个训练折实际为全批量，减少图传播的批次开销）
optimizer           AdamW
learning rate       1e-3
weight decay        1e-3
gradient clip       1.0
epochs              40（Stage 1所有架构固定相同更新预算）
```

预计参数量约1.5万至3.5万。这个规模大于V5/V7，足以表示节点和链条；相对382台开发车仍受控。首轮不扩到百万或千万参数。

Stage 1的目的只比较网络结构，因此四个架构统一固定训练40轮，不让每个架构再通过小型内层验证获得不同训练预算。外折验证车不参与缩放、正例权重或训练。若某一结构通过Stage 1，Stage 2再在各外折训练车辆内部选择轮数；外折验证车仍不能参与选轮。

## 7. 执行顺序和停止规则

### 第一阶段：必须完成

1. V10-A：建立相同输入下的深度时序基线。
2. V10-B：验证角色和风险阶段表示。
3. V10-C与V10-C-shuffle：成对验证风险链拓扑。

### 第二阶段：有条件继续

- C相对B方向改善，并且C优于C-shuffle，才运行V10-D。
- D没有明显恶化主AUC和Brier，才运行V10-E。
- 如果A已经明显低于V7无注意力对照，先检查实现和缩放，不通过加更多模块补救。

接受一个结构至少满足：

1. 20→40 OOF AUC方向改善；
2. 配对车辆bootstrap区间不明显偏负；
3. Brier没有显著恶化；
4. 五折结果不是单折驱动；
5. 对应的结构压力测试通过。

差值很小且区间跨0时选择更简单版本。V3只作为外部成绩参照，不用它决定V10内部每一步是否继续。

## 8. 必须通过的结构测试

| 测试 | 通过标准 |
|---|---|
| 锚点截断 | 修改锚点后的全部数据，预测逐位不变 |
| 因果卷积 | 第`d`天辅助预测不随`d+1`之后输入改变 |
| 合理图vs随机图 | 同参数条件下合理图至少方向更好；否则不声称链条有效 |
| 日期置乱 | Chain分支贡献应下降；静态暴露分支变化较小 |
| 边删除 | 删除某条边只影响其下游消息，不破坏自通道 |
| DMS遮蔽 | 低质量时视觉事件归入低证据先验，风险不能机械下降 |
| 等比例放大事件和暴露 | 对应单位暴露表示基本稳定 |
| 稀疏事件删除 | 删除历史事故单项后网络仍能依靠未遂和近端节点工作 |
| 标签置换 | 完整训练和选轮流程AUC回到随机范围 |

## 9. 解释输出

V10不只保存最终概率，还保存：

- 每类事件在各折的平均动态gate；
- 遮蔽每类事件或每个角色后的配对概率变化；
- 每条图边的学习强度和1–7天滞后分布；
- 慢性、急性和升级三部分对最终logit的贡献；
- DMS证据可靠度及质量遮蔽压力测试结果；
- C与C-shuffle的逐车配对预测。

这些量用于解释模型如何使用事件，不能称为行为的因果效应或客观严重度。

## 10. 与已有版本的关系

- **不使用V3模型或V3汇总特征。** V10从每日节点序列独立训练。
- **继承V7的数据边界。** 每个锚点只输入已有日序列，最终Day60输入完整60天。
- **继承V3–V9的监督协议。** 标签、右删失损失、382/96车辆划分和5折不变，保证指标可比。
- **吸收V9的失败信息。** 不再把风险链压成少量静态比例，也不使用只有数百参数的静态HNAM；风险链在逐日隐藏状态中学习。
- **暂不重复暴露乘法分解。** V9-E4没有证明收益。V10保留暴露节点和单位暴露输入，但首轮风险头直接输出`q`。

## 12. 实际训练结果与决定

### 12.1 Stage 1：结构消融

运行`V10S1_20260923_145411_d9aec959`使用相同的23,156个注册参数、相同五折和固定40轮预算：

| 变体 | 20→40 OOF AUC | Brier | Accuracy@0.5 |
|---|---:|---:|---:|
| Flat | 0.7331 | 0.1856 | 0.7147 |
| Role | 0.7578 | 0.1791 | 0.7382 |
| Chain | **0.7611** | **0.1781** | 0.7251 |
| Chain-shuffle | 0.7591 | 0.1787 | 0.7356 |

Role相对Flat的配对ΔAUC为**+0.0247**，95%区间`[+0.0023,+0.0493]`。Chain相对Role为**+0.0033**，区间`[-0.0021,+0.0086]`；Chain相对同参数乱序图为**+0.0020**，区间`[-0.0014,+0.0056]`。角色和阶段组织有正向证据；具体风险链拓扑只有方向性优势，尚未被区间证实。

### 12.2 Stage 2：中间阶段监督

运行`V10S2_20260923_151111_fc2709b4`在每个外折训练车内部按车分层留出18%选择轮数，最少15轮、最多60轮；外折验证车不参加选轮。Chain-Aux相对同协议Chain：

| 变体 | 20→40 OOF AUC | PR-AUC | Brier |
|---|---:|---:|---:|
| Chain | 0.7543 | 0.5416 | 0.1789 |
| Chain-Aux | **0.7629** | **0.5501** | **0.1781** |

配对ΔAUC为**+0.0086**，95%区间`[-0.0025,+0.0199]`。主检查点方向改善且Brier未恶化，所以按预注册条件继续质量门控；但40→20、50→10和53→7均有所下降，辅助任务收益不能视为稳定结论。

### 12.3 Stage 3：质量门控

运行`V10S3_20260923_152406_40e98aaf`中，Quality-Chain的20→40 AUC为**0.7612**、Brier为**0.1786**；相对Chain-Aux的ΔAUC为**−0.0017**，区间`[-0.0072,+0.0040]`。它在50→10和53→7略好，但没有改善主检查点，因此不替换Chain-Aux。

### 12.4 学到的事件作用

对Stage 2五个外折模型逐一遮蔽单类事件信号，再在相同382台OOF车辆重算AUC。AUC下降较多的是左车道偏移**0.0117**、右车道偏移**0.0085**、长时间压线**0.0046**、车距过近**0.0031**和前碰撞预警**0.0029**。完整结果保存在`event_importance.csv`与`event_ablation_oof.csv`。

这只是模型依赖度：相关事件、事件稀疏度、标签定义和网络路径都会影响排名。平均动态gate大多接近0.5，不能把gate值直接解释为严重程度；遮蔽AUC变化也不是行为的因果效应。

### 12.5 最终决定

V10内部保留Chain-Aux，三列候选为Stage 2运行目录中的`deliverables/task1_v10_predictions.csv`。它比V7无注意力对照高**0.0046 AUC**，区间`[-0.0280,+0.0375]`；比V3低**0.0246**，区间`[-0.0588,+0.0092]`。差异均未得到明确统计支持，按简化优先规则，项目主候选仍为V3，V10作为最完整的深度学习风险链对照保留。96台锁定车未评分，Day60→未来40天仍无本地真实成绩。
