## 已完成实验

### V3M0_20260921_155138_475c1ea1 — 固定 landmark 线性日风险率

- **版本目录：** `E:\Databases\2026 清华IE亮剑-算法赛道赛题\任务一实验结果\runs\V3M0_20260921_155138_475c1ea1`，同目录含源代码快照、折模型、开发集 OOF、指标和 500 车候选预测。状态 `completed`。
- **方案：** 日末锚点 `{14,20,30,40,50,53}`；历史压成长期、近期变化、暴露量、质量特征。固定日风险 `q`，按首次后续事件日或第 60 天右删失，损失压缩为每锚点至多两条加权记录。Elastic-net 逻辑回归 `C=0.1, l1_ratio=0.2`，未用本轮 OOF 选超参；5 折内分别填补、截尾和标准化。
- **监督与划分：** 478 台曾有可匹配事件记录的车保留为候选监督集；不要求锚点前已有报警。382 台开发车 5 折 OOF，96 台锁定车未拟合或评分。第 20 天标签与 V1 冻结标签逐车一致；修改第 20 天以后的里程及 near-miss 记录，不改变任何一台车第 20 天的输入特征。
- **主回测：** 382 台、119 正例；20→40 AUC **0.7875**，车辆 bootstrap 95% 区间 **[0.7374, 0.8384]**；PR-AUC **0.5949**，Brier **0.1679**，Accuracy@0.5 **0.7539**。同车 V1 AUC **0.7073**，配对 ΔAUC **+0.0802**，bootstrap 区间 **[+0.0458, +0.1161]**。V1 曾把锚点前无报警记录的车送入回退模型，V3 修正了这一资格误判；因此差值是**整套方案**的比较，不能单独归因于 survival loss 或线性模型，也不涵盖反复试验选型的额外不确定性。
- **其他锚点：** 14→40 AUC **0.7840**；30→30 **0.7900**；40→20 **0.7837**；50→10 **0.7471**；53→7 **0.7259**。预测期、基率不同，各行分别解释；14→40 与 20→40 是同一批车辆，不能当作两组独立样本。
- **无事件输入对照：** 开发车去除事件衍生特征后，20→40 OOF AUC **0.7179**、Brier **0.1899**。这说明事件特征对本地回测有价值，但不证明事件表逐日完整。
- **Day60 候选：** 478 台有可匹配事件记录的车用完整模型；其候选概率均值 **0.4711**，高于 20→40 OOF 均值 **0.3046**。其余 22 台不仅事件表无匹配记录，轨迹与 IMU 也无记录，使用开发车 20→40 正例率 **0.3115** 作为低证据先验，未使用无行为依据的回退模型概率。不能由此判断这 22 台真的没有传感器，也不能验证 60→未来40 天校准。
- **历史版本：** 较早的 `V3M0_20260921_154739_c484ef61` 保留作审计；它把 22 台无行为观测车送入回退模型，得到相同且偏低的概率 **0.1007**。本版只修正无观测车辆路由，382 台开发车 OOF 完全相同。
- **下一步：** 先审计事件标签的独立覆盖信息和 Day60 分布变化；再用相同锚点、损失与折划分试浅层 CatBoost。96 台锁定组继续不评分。

### V2_20260921_135210_2fac9c14 — 60 天序列神经网络

- **版本目录：** `E:\Databases\2026 清华IE亮剑-算法赛道赛题\任务一实验结果\runs\V2_20260921_135210_2fac9c14`。同目录保存 `source/` 当版代码、配置、6 个模型权重与标准化器、训练日志、开发集 OOF、辅助回测和 500 车候选预测。状态 `completed`。
- **固定方案：** 每折在训练车辆完整 60 天上预训练 5 轮遮蔽重建，再在 20/30/39/46/53 天锚点的完整可观察标签上监督训练 35 轮。四模态投影 + 单层双向 GRU + 单调五段风险头；AdamW，隐藏宽 24，事件模态屏蔽概率 0.15。当前机器安装的 PyTorch 为 `2.14.0+cpu`，本次使用 CPU；代码的 `auto/cpu/cuda` 设备选择可用于匹配的 CUDA 安装。
- **划分与泄漏检查：** 与 V1 完全同一冻结车辆名单：382 台开发车做 5 折 OOF，96 台锁定车未参与标准化、预训练、监督拟合或评分。06-20 主 OOF 与预处理标签逐车一致。折内标准化仅在训练车前 20 天拟合；遮蔽预训练只读取训练车完整 60 天。新增测试验证了锚点之后的数据不会改变该锚点预测。
- **20→40 主回测：** 382 台、119 正例，ROC-AUC **0.6946**，车辆 bootstrap 95% 区间 **[0.6379, 0.7507]**；Accuracy@0.5 **0.7016**，PR-AUC **0.4967**，Brier **0.2336**。五折 AUC 约 **0.5841–0.7972**，折间差异明显。
- **与 V1 同车配对：** AUC 差值 **−0.0127**；车辆配对 bootstrap 1000 次区间 **[−0.0754, 0.0496]**，没有证据说明网络在主代理任务胜出。PR-AUC 小幅增加，但概率误差 Brier 从 0.1966 升至 0.2336，因此暂不替换 V1 为首选。
- **长历史短预测期：** 30→30 AUC **0.7085**，39→21 **0.7194**，46→14 **0.7333**，53→7 **0.6306**；各指标对应不同预测期和事件基率，不能直接互相排名，也不是 60→40 AUC。
- **候选推理：** 使用开发车重训后，对 500 台唯一车辆输入完整 60 日序列，得到 40 天候选概率，范围约 `[0.0030, 0.9971]`。其中 22 台无事件源车辆依赖模态缺失回退，风险估计缺少真实标签检验。锁定组虽有候选概率，但标签未读取或评分。
- **结论与下一步：** 保留这一版作为可复现的神经网络主线；下一轮先在同一车辆划分做“关闭 60 天遮蔽预训练”消融，再检查事件模态遮蔽和风险头校准。现有数据没有 07-30 以后的事故标签，不能声明已验证 60→未来40 天实际成绩。

### V1_20260921_112800_71fbec41 — 首版 CatBoost 基线

- **版本目录：** `E:\Databases\2026 清华IE亮剑-算法赛道赛题\任务一实验结果\runs\V1_20260921_112800_71fbec41`，含当版 `source/`、折模型、开发集 OOF 和 500 车候选预测。状态 `completed`，CPU 训练。
- **固定方案：** 06-20 前 20 天的 7/14/20 天 near-miss、事件率与行驶暴露量；CatBoost 400 次迭代、深度 4，另设只用暴露量的回退模型。超参在训练前写入配置，未根据本次外折结果挑选；分类阈值固定为 0.5。
- **划分：** 478 台可监督车辆中，382 台开发、96 台锁定。开发组 5 折 OOF，每台验证车一次；`leakage_audit.json` 通过，锁定组没有参与拟合或指标计算。
- **开发集 OOF：** 382 台、119 正例。ROC-AUC **0.7073**，车辆 bootstrap 95% 区间 **[0.6470, 0.7649]**；PR-AUC **0.4891**，Brier **0.1966**。Accuracy@0.5 **0.7042**、召回率 **0.3613**、特异度 **0.8593**、F1 **0.4322**；混淆矩阵 `TN=226, FP=37, FN=76, TP=43`。各折 AUC 约 **0.6651–0.7594**。开发集正例率约 0.3115，全部预测负例的准确率约 0.6885，因此单看准确率的提升较小。
- **缺事件源回退：** OOF 中 344 台走完整模型、38 台走暴露量回退；后者仅有 3 个正例，其组内 AUC 约 0.1333，样本太少且与最终完全无事件源车辆的分布不同，不能把这个数字当作可靠的外推性能。把所有开发车都模拟走回退分支时，整体 AUC 为 **0.6862**。500 车候选预测中 478 台走完整分支、22 台走回退分支。
- **特征检查：** 开发集最终模型的重要性靠前的特征包括最近 7 天里程变化、7 天驾驶时长、20 天事件总数等。这是模型内描述，不等于因果关系。
- **产物复核：** 382 条 OOF 的车辆和标签与预处理表一致，OOF 与锁定组不重叠；500 条候选预测设备号唯一，概率约在 `[0.0463, 0.9460]`。
- **结论与下一步：** 保留为首版可复现基线，暂不将其作为最终优选模型。优先审计 329 台暂定负例的未来事件源覆盖，并针对缺事件源车辆验证回退策略；之后再比较更强的树模型、特征消融与时序模型。尚未计算锁定组分数，也不能报告 60→40 实测效果。
